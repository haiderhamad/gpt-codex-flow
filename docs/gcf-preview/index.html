Start with one folder.

Node.js 20+, npm and Git. Install from the public GitHub repository. The npm package is not published; use the source installation below.

STEP 1

Prepare the bridge

Clone the public repository, enter its folder and install the locked dependencies. Run these commands in Terminal; npm ci must run inside gpt-codex-flow.

Terminal · project folder
git clone https://github.com/haiderhamad/gpt-codex-flow.git
cd gpt-codex-flow
npm ci
STEP 2

Open Control Center

Paste the one-time Terminal code. Add Folder, confirm locally, then open Connections.

Recommended: local browser setup
npm run gcf:ui
Optional: check prerequisites
npm run gcf:doctor
STEP 3

Connect and verify

Start Cloudflare Quick Tunnel manually in Control Center. Verify access from ChatGPT.

Terminal · health and connection instructions
npm run gcf:doctor

Local verification checks folder access. Confirm the connection separately in your actual client.

Connect ChatGPT with Cloudflare Quick Tunnel

Open Control Center, approve a project, and start the tunnel manually. Copy its private connection URL into ChatGPT and verify access.

Open Control Center
npm run gcf:ui

Private URL: keep the embedded token secret. The URL changes on restart. Tunnel ready does not prove ChatGPT is connected.

Read Only protects your source files, not handoff notes: GCF can still save scoped future-task instructions inside .ai-bridge/. These notes never launch Codex or authorize execution. Command allowlists are not a sandbox; project scripts run locally. Native Codex sandbox settings apply only to Codex-launched work. Full Access is manual and high risk.

Cloudflare Quick only: a temporary development/test tunnel with no uptime guarantee. Start and stop it in Control Center. A previous isolated ChatGPT connection succeeded; test your own connection. Keep the token-bearing URL private.
